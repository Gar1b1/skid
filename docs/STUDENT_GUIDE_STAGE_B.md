# SkiDB UI — שלב ב: טיפוסי Integer ו-Boolean

בשלב ב ה-DBMS שלכם צריך לתמוך בשלושה טיפוסי שדות: `String`, `Integer` ו-`Boolean`.
לשלב הזה יש JAR חדש: **skidb-ui-2.0.jar**.

ההתקנה וכתיבת ה-Adapter זהות לשלב א. אם עוד לא קראתם, התחילו מ[מדריך החניך](STUDENT_GUIDE.md).

---

## 1. מעבר מ-1.0 ל-2.0

1. הורידו את הקבצים החדשים:
   - https://github.com/Gar1b1/skid/raw/main/dist/skidb-ui-2.0.jar
   - https://github.com/Gar1b1/skid/raw/main/dist/skidb-ui-2.0-sources.jar (רשות)
2. בתיקייה `lib/` החליפו את `skidb-ui-1.0.jar` ב-`skidb-ui-2.0.jar`. מחקו את הישן, כדי ששני הקבצים לא יהיו בפרויקט יחד.
3. עדכנו את הספרייה בסביבת הפיתוח, כמו בשלב 2 של מדריך החניך. ב-Maven שנו את הגרסה ל-`2.0` והריצו שוב את `install:install-file` עם הקובץ החדש.

**הממשק `SkiDBAdapter` לא השתנה**, כך שה-Adapter שלכם משלב א ממשיך לעבוד כמו שהוא. מה שמשתנה הוא הערכים שהוא מקבל.

## 2. הטיפוסים

| טיפוס בסכמה | המחלקה ב-Java שתקבלו ב-`value` | דוגמה |
|---|---|---|
| `"String"` | `String` | `"Israel"` |
| `"Integer"` | `Integer` | `21` |
| `"Boolean"` | `Boolean` | `true` |

לדוגמה, ב-`addRecord` תקבלו:

```java
{"firstName" -> "Israel", "age" -> 21, "isCommander" -> true}
//               String           Integer             Boolean
```

בדקו את הטיפוס של ערך בעזרת `instanceof`, למשל `value instanceof Integer`.

---

## 3. מה חדש ב-UI

- **יצירת אוסף:** לכל שדה יש עכשיו בחירה של טיפוס: `String`, `Integer` או `Boolean`.
- **טופס הרשומה:** ליד כל שדה יש בחירת טיפוס ("send as"). ברירת המחדל היא הטיפוס מהסכמה, וה-UI ממיר את מה שהקלדתם לטיפוס הזה לפני השליחה.
  - ב-`Integer` הקלידו מספר שלם, למשל `21`.
  - ב-`Boolean` הקלידו `true` או `false`.
  - אם הערך שהקלדתם לא מתאים לטיפוס, למשל `abc` ב-Integer, ה-UI יתריע ולא ישלח כלום.
- **שליחת טיפוס שגוי בכוונה:** שנו את הטיפוס של שדה, והבחירה תיצבע באדום. למשל, בחרו `String` לשדה `age` והקלידו `21`; ה-UI ישלח את המחרוזת `"21"` במקום המספר `21`. **ה-DBMS שלכם צריך לדחות את זה.**
- **הטבלה:** ערך שהטיפוס שלו לא תואם לסכמה מוצג **באדום**. מעבר עם העכבר על תא מראה את הטיפוס שלו.

## 4. בדקו את העבודה שלכם

בנוסף לרשימה של שלב א:

- [ ] יצירת אוסף `matmonDB` עם `firstName: String`, `age: Integer`, `isCommander: Boolean` → מופיע ברשימה
- [ ] הוספת key `1` עם `Israel`, `21`, `true` → מופיע בטבלה, בלי אדום
- [ ] הוספת key `2` כש-`age` נשלח כ-**String** (`"21"`) → **שגיאה**
- [ ] הוספת key `3` כש-`isCommander` נשלח כ-**String** (`"true"`) → **שגיאה**
- [ ] הוספת key `4` כש-`firstName` נשלח כ-**Integer** (`5`) → **שגיאה**
- [ ] Update ל-key `1` כשרק age = `22` → בטבלה `22`, ושאר השדות לא השתנו
- [ ] Update ל-key `1` כש-age נשלח כ-**Boolean** (`true`) → **שגיאה**, והרשומה לא השתנתה
- [ ] Get ל-key `1` → הטופס מתמלא, וכל שדה מוצג עם הטיפוס הנכון
- [ ] אין אף תא אדום בטבלה

## 5. פתרון בעיות

| בעיה | פתרון |
|---|---|
| הכותרת בחלון היא `SkiDB — Stage A` ואין בחירת טיפוסים | אתם עדיין מריצים את ה-JAR הישן. ודאו שרק `skidb-ui-2.0.jar` נמצא בספריות של הפרויקט. |
| תא אדום בטבלה | ה-DBMS שלכם שמר ערך מטיפוס שגוי. הוסיפו בדיקת טיפוס ב-`addRecord` וב-`updateRecord`. |
| `ClassCastException` | הקוד שלכם הניח טיפוס מסוים, למשל המיר ל-`String` ערך שהוא `Integer`. בדקו עם `instanceof` לפני ההמרה. |
